# Logger source

Imported from https://github.com/dhartman2007/SeeStar-Logger at commit
151f2db75da22405323d24c5c5fa359350e9ac54.

The original collector, candidate providers, desktop launchers, local viewer and
tests are retained. Suite adaptations add environment-based configuration,
shared saved location/key references, configurable time zone, and a Unix
single-writer lock. Run standalone desktop launchers from this directory if
needed; use the suite's Logger workspace for shared configuration.
