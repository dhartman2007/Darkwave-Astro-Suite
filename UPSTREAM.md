# Source provenance

Darkwave Astro Suite was imported from
https://github.com/dhartman2007/Astrophotography-Planner/tree/6254235848faee41c5a991b97b44259a3d399493
(source pull request #1, branch `codex/darkwave-astro-suite`).

The import preserves the complete application snapshot, including the OpenNGC
catalog CSVs, PDF fonts, logger, launchers, and tests. The original repositories
and their main branches remain separate. The source snapshot does not include
personal databases, settings, credentials, or runtime output; previous source
repository Git history is not imported.

Logger provenance is recorded in `logger/UPSTREAM.md`. OpenNGC attribution and
license are recorded in `data/OpenNGC-README.md`; font licensing is retained in
`fonts/LICENSE.txt`. Existing upstream attribution is preserved.

Import-specific changes: standalone setup/migration instructions, this provenance
record, and an automated test workflow. Application files remain unchanged from
the source snapshot.
